# Fresh Mind Landing Page

Static landing page and launch legal pages for Fresh Mind.

## Pages

- `index.html`
- `privacy/index.html`
- `terms/index.html`

## Local preview

Run a static server from this folder:

```sh
python3 -m http.server 4173
```

Then open `http://127.0.0.1:4173/`.
